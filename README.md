# NUR — Halaqah Tahfiz Quran (Indonesia)

Bilingual (Arabic / Indonesian) site for managing a Quran memorization circle in Indonesia.
موقع عربي / إندونيسي لإدارة حلقة تحفيظ قرآن.

## Use / الاستخدام

- Open `index.html` (no server needed — data is stored in the browser via LocalStorage).
- Register → you get a personal login code.
- Login codes:
  - `111` → admin panel (students, halaqat + codes, news)
  - Halaqa code (e.g. `1122`) → list that halaqa's students
  - Personal code (e.g. `5001`) → student report (attendance, grades, progress, homework)

## Files

- `index.html` — pages
- `styles.css` — calm UI
- `app.js` — logic + LocalStorage
